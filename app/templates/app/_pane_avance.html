Démarrage et santé

Vide : ce que prévoit l'image. Une seule ligne, découpée comme dans un terminal (les guillemets regroupent) ; aucun shell n'interprète la commande : pour enchaîner, écris sh -c "…".

Lancée dans le conteneur toutes les 15 s ; code de sortie 0 = en bonne santé, 3 échecs de suite = malade.{% if not kind.http %} Le déploiement attend qu'elle réussisse (sinon la version précédente revient) et la supervision t'alerte si elle échoue.{% else %} La santé de l'appli reste vérifiée par {{ a.health_path }} ; celle-ci s'ajoute dans l'état Docker.{% endif %}
{% if kind.http %}
« Tout code sous 500 » : une appli qui répond 401 ou 404 est considérée en marche. Plus strict : une page d'erreur fait échouer le déploiement et déclenche l'alerte.
{% endif %}
« www:/var/www/html » garde /var/www/html dans data/www : sauvegardé, restauré et déplacé avec data/. Pour les images qui ne rangent pas leurs données dans /data.
{% endif %} {% if kind.http %}

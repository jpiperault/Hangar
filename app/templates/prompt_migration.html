Prompt de migration

Pour amener dans Hangar les données d'une instance de l'appli hébergée ailleurs. Remplis ce que tu sais, copie le prompt et colle-le dans Claude, dans le dépôt de l'appli : il y crée un kit (migration/export.sh, verify.sh, MIGRATION.md). Le fichier produit sur l'ancien serveur s'envoie ensuite dans Sauvegardes › Importer des données dans une appli. Un champ vide garde son <…> : Claude posera la question.

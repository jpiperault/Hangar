Brancher Claude (serveur MCP)
  1. Télécharge hangar-mcp (un fichier Python, sans dépendance) sur l'ordinateur où tourne Claude Code.
  2. Crée un jeton ci-dessous (« lecture » pour diagnostiquer, « déploiement » pour aussi déployer).
  3. Puis, dans un terminal :
claude mcp add hangar -e HANGAR_URL={{ api_url }} -e HANGAR_TOKEN=hgr_… -e HANGAR_FINGERPRINT={{ api_fp or '…' }} -- python3 /chemin/vers/hangar-mcp
L'empreinte épingle le certificat auto-signé de la console : une autre machine se faisant passer pour elle est refusée. Le serveur demande à Claude de te confirmer tout déploiement ou arrêt avant de le lancer.

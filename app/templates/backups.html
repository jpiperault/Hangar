L'identifiant fourni par défaut avec rclone est partagé par tous ses utilisateurs, et Google le bloque souvent (« quota dépassé »). Le tien est gratuit et son quota t'est réservé. Guide détaillé : docs/google-drive.md.

{% if not s.home %}

Il faut d'abord un domaine avec un préfixe pour les routes par chemin (page Domaines) : Hangar y publie les deux pages que Google exige.

{% endif %}
  1. Projet : sur console.cloud.google.com, crée un projet « Hangar ».
  2. API : dans API et services › Bibliothèque, active Google Drive API.
  3. Google Auth Platform : ouvre Google Auth Platform et clique sur « Commencer » : nom de l'application « Hangar », ton adresse e-mail d'assistance, audience Externe, ton adresse comme contact, puis « Créer ».
  4. Branding : remplis la partie « Domaine de l'application », puis « Enregistrer » en bas de page. {% if s.home %}
    Page d'accueil
    https://{{ s.home }}/
    Règles de confidentialité
    https://{{ s.home }}/confidentialite
    Conditions d'utilisation
    laisser vide
    Domaines autorisés
    « + Ajouter un domaine » : {{ s.domain }} (sans https:// ni préfixe)
    Logo
    n'en mets pas : un logo oblige à faire valider l'application (plusieurs jours)
    Hangar sert lui-même ces deux pages : vérifie que la page de confidentialité s'ouvre.{% endif %}
  5. Accès aux données : « Ajouter ou supprimer des champs d'application », coche …/auth/drive.file (« Afficher, créer et supprimer uniquement les fichiers que vous utilisez avec cette appli »), « Mettre à jour », puis « Enregistrer ».
  6. Audience : « Publier l'application », puis « Confirmer ». L'état doit passer à En production. Indispensable : en mode « Test », Google coupe l'accès au bout de 7 jours et les sauvegardes s'arrêtent. Le droit drive.file ne demande pas de validation par Google. S'il te demande quand même de prouver que {{ s.domain or 'le domaine' }} t'appartient : dans Search Console, ajoute une propriété « Domaine », puis l'enregistrement TXT google-site-verification=… qu'il donne dans le DNS chez Cloudflare (nom @), et clique sur « Valider ».
  7. Clients : « Créer un client », type Application de bureau, nom « Hangar ». Copie l'ID client et le code secret dans les champs ci-dessous (le secret n'est affiché en entier qu'à la création : télécharge le JSON au besoin).
  8. Connexion : clique sur « Connecter Google Drive ». Google affiche « Google n'a pas validé cette application » : c'est normal, clique sur « Paramètres avancés », puis « Accéder à Hangar (non sécurisé) », coche l'accès aux fichiers et « Continuer ».

Archives à télécharger

Un fichier .tar.gz avec, pour chaque appli, sa fiche (image, version, variables), l'export de sa base et son dossier data/. Il se restaure ici ou sur un autre serveur Hangar : les applis absentes sont recréées. Il n'est pas chiffré et contient tes secrets (variables d'environnement, mots de passe des bases) : range-le en lieu sûr. Les 10 dernières archives sont gardées sur le serveur.

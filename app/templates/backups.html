Étape préalable : ton identifiant Google (10 minutes, une seule fois)

L'identifiant fourni par défaut avec rclone est partagé par tous ses utilisateurs, et Google le bloque souvent (« quota dépassé »). Le tien est gratuit, et son quota t'est réservé.

  1. Ouvre console.cloud.google.com et crée un projet « Hangar ».
  2. Dans API et services › Bibliothèque, active Google Drive API.
  3. Dans Google Auth Platform, clique sur « Commencer » : nom de l'application « Hangar », ton adresse e-mail, audience Externe.
  4. Dans Accès aux données, ajoute le champ d'application …/auth/drive.file.
  5. Dans Audience, clique sur Publier l'application (« En production »). En mode « Test », Google coupe l'accès au bout de 7 jours. Le droit drive.file ne demande aucune validation par Google.
  6. Dans Clients, crée un client de type Application de bureau, nommé « Hangar ». Copie son ID client et son code secret ci-dessous.
Laisse vide pour essayer avec l'identifiant partagé de rclone (déconseillé).
